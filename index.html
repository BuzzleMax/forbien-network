Quick Installation Guide

Get ForBien running on your Android device in 7 simple steps

  1. Download ForBien APK: Tap the "Download ForBien APK" button above to obtain the latest APK file.
  2. Open Downloaded File: Open ForBien.apk from your browser downloads or file manager.
  3. Allow Installation: If prompted by Android, grant permission to install apps from external sources.
  4. Install ForBien: Tap Install to complete app setup.
  5. Launch App: Open ForBien directly from your home screen or app drawer.
  6. Grant Permissions: Accept requested Bluetooth and Location (GPS) hardware permissions.
  7. Begin Offline Mesh Communication: You are ready! Test BLE mesh emergency message delivery with nearby ForBien devices.

App Hardware Permissions

Why ForBien requires specific hardware access

Bluetooth Access

Required for BLE mesh networking. Enables direct device-to-device communication and message hopping between nearby devices without internet infrastructure.

Location Access

Necessary for BLE scanning on Android. Used to discover nearby mesh network participants and optimize routing paths based on device proximity.

Background Scanning

Essential for maintaining mesh network connectivity while the app runs in the background. Ensures continuous message routing and network participation.
