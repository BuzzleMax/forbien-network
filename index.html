App Hardware Permissions

Why ForBien requires specific hardware access

Bluetooth Access

Required for BLE mesh networking. Enables direct device-to-device communication and message hopping between nearby devices without internet infrastructure.

Location Access

Necessary for BLE scanning on Android. Used to discover nearby mesh network participants and optimize routing paths based on device proximity.

Background Scanning

Essential for maintaining mesh network connectivity while the app runs in the background. Ensures continuous message routing and network participation.
